# qHexWalker
Qt app using H3 and MapLibre to display geocells.
The project is used https://github.com/maplibre/maplibre-native-qt for displaying map.
You need to build it for the project, here it is the instruction: https://maplibre.org/maplibre-native-qt/docs/
